🎧 TrackList

Zene. Értékelések. Közösség.

A TrackList egy fejlesztés alatt álló, Rate Your Music és AniList ihlette zenei közösségi webalkalmazás.

A felhasználók albumokat és zeneszámokat fedezhetnek fel, értékeléseket írhatnak, saját listákat készíthetnek, valamint bejegyzéseket oszthatnak meg egy közösségi hírfolyamban.

🛠️ Technológiák

    Frontend: React, JavaScript, HTML, CSS
    Backend: C#, ASP.NET Core Web API
    Adatbázis: MySQL
